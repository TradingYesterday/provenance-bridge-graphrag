# 标注说明

2Wiki 的 `supporting_facts` 不够用来判断关系方向、身份和合法依赖。先导题需要单独的 gold，并且不能由本系统的抽取器或验证器产生。

每题至少记录：

- 非末跳的缺边：头、关系、尾，以及方向
- 支持该关系的原文：文档、句子下标、连续 quote、字符区间
- 桥实体在当前图中的 ID；若有同名实体，写下为什么能或不能消歧
- 后继约束，以及重入后应该取回的图边
- 是否存在别名边或替代路径
- 这题是否属于单答案关系问答；计数、比较、时间限定、错误入口记入不适用清单

模型可以提出候选标注。写入评价 gold 之前要人工核对。控制缺边实验另用离线构造器删除桥边，gold 条件不能进入运行时调度。
